# Componentes Utilizados

## Hardware

- Arduino Uno
- Display LCD I2C 16x2
- LED Verde
- LED Vermelho
- Buzzer
- Push Button
- Resistores 220 Ω
- Protoboard
- Jumpers

## Função de Cada Componente

### Arduino Uno

Responsável pelo controle de toda a lógica do sistema.

### Display LCD I2C

Exibe informações do jogo, estatísticas e mensagens ao usuário.

### LED Verde

Representa o estímulo GO.

### LED Vermelho

Representa o estímulo NO-GO.

### Buzzer

Fornece feedback sonoro para eventos do jogo.

### Botão

Permite ao participante responder aos estímulos.

### Protoboard e Jumpers

Utilizados para montagem e conexão dos componentes.
