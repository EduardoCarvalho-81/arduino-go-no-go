# Funcionamento do Projeto Go/No-Go

## Objetivo

O projeto Go/No-Go foi desenvolvido para trabalhar atenção seletiva, controle inibitório e tempo de reação utilizando Arduino.

## Conceito

O teste Go/No-Go é amplamente utilizado em neurociência para avaliar a capacidade de responder rapidamente a estímulos corretos e inibir respostas inadequadas.

## Regras

### GO

Quando o LED verde acende, o participante deve pressionar o botão.

### NO-GO

Quando o LED vermelho acende, o participante não deve pressionar o botão.

## Recursos do Sistema

- Contagem de acertos
- Contagem de erros
- Sistema de vidas
- Aumento progressivo da dificuldade
- Medição do tempo de resposta
- Registro do melhor tempo
- Cálculo da média de desempenho
- Classificação final do jogador

## Componentes Utilizados

- Arduino Uno
- Display LCD I2C 16x2
- LED Verde
- LED Vermelho
- Buzzer
- Botão Push Button
- Resistores 220 Ω
- Protoboard
- Jumpers

## Competências Desenvolvidas

- Atenção seletiva
- Controle inibitório
- Coordenação motora
- Pensamento computacional
- Lógica de programação
- Robótica educacional

## Aplicação Educacional

Projeto desenvolvido para a Feira do Conhecimento com o objetivo de integrar programação, eletrônica, neurociência e robótica educacional em uma atividade prática e interativa.
