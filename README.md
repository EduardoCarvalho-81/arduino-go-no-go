# Arduino Go/No-Go

## Sobre o Projeto

O Go/No-Go é uma atividade amplamente utilizada em neurociência cognitiva para avaliar atenção seletiva, controle inibitório e tempo de reação.

Este projeto utiliza Arduino para criar uma versão física e interativa do teste, permitindo que os participantes respondam a estímulos visuais por meio de um botão.

---

## Objetivos Educacionais

- Desenvolver atenção seletiva
- Trabalhar controle inibitório
- Exercitar tomada rápida de decisão
- Introduzir conceitos de programação embarcada
- Aplicar conhecimentos de eletrônica e robótica educacional

---

## Funcionamento

O Arduino acende LEDs aleatoriamente.

### GO

✅ Quando o LED verde acende, o participante deve pressionar o botão.

### NO-GO

❌ Quando o LED vermelho acende, o participante não deve pressionar o botão.

O sistema pode registrar:

- Acertos
- Erros
- Tempo de reação
